# Audit fixtures

Independently labelled clear-cut cases for regression.

- Labels are derived from evidence checks, not copied from `output/`.
- Each case has one dominant story (single-alert closes, TM22-only list decisions, fraud escalations, etc.).
- `must_cite` lists evidence/list IDs the system should include when non-empty.
- `accepted_reason_codes` optionally allows equivalent escalate codes for network patterns.

See `manifest.json` for counts by institution and pattern.
